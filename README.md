# AstrBot 伪造转发插件 (astrbot_plugin_fake_forward)

基于 `astrbot_plugin_SessionFaker` 重构的伪造合并转发消息插件。

## 功能

- **伪造合并转发**：生成包含多个发送者的聊天记录
- **自定义昵称**：支持 `#昵称` 语法，优先于 API 获取
- **自动获取 QQ 昵称**：远梦 API（免费）
- **图片/视频分步发送**：先发命令，再逐一发送媒体，进度提示 `已上传: N/M`
- **完整交互流程**：预览、回退、确认、取消
- **任务隔离**：按 QQ 号隔离任务，互不干扰
- **权限控制**：通过 WebUI 配置可使用者列表（白名单）
- **调试日志**：可开关，便于排查问题

## 重构/改进点

- **权限控制**：白名单，可配置可使用者
- **交互流程**：预览、回退、确认、取消，流程完整
- **任务隔离**：按 QQ 号隔离，互不干扰
- **自定义昵称**：支持命令中指定 `#昵称`
- **配置文件**：可调整 API 密钥（免费）、超时时间、可使用者列表
- **新 API**：远梦 API（原 API 已迁移）

## 指令

| 命令 | 说明 |
|------|------|
| `/伪造消息 QQ号#昵称 内容 \| QQ号 内容` | 创建伪造消息任务 |
| `/伪造确认` | 确认发送合并转发 |
| `/伪造回退` | 撤销上一个已上传的媒体 |
| `/伪造预览` | 预览当前状态，未填充显示 `[资源]` |
| `/伪造取消` | 取消当前任务 |
| `/伪造帮助` | 显示帮助信息 |

## 标题

合并转发消息的外部卡片标题由第一个发言者的昵称决定（格式：`{昵称}的聊天记录`）。
你可以通过 `#昵称` 自定义昵称来改变标题。

## 常见问题

**Q：为什么合并转发中的文件是 0 字节？**
A：NapCat 的路径访问限制，插件层面无法解决。

**Q：自定义标题不生效？**
A：自定义标题需要从私聊中转发才可生效，群内直接发送无效。从群转私聊再转发也无效。

**Q：如何开启调试日志？**
A：在 WebUI 插件设置中将 `debug_mode` 设为 `true`，重启插件即可。
